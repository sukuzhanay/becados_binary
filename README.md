# Lectura de solicitudes y escritura binaria

Ejercicio de C++ que lee solicitudes de beca desde texto y escribe las aceptadas en formato binario.

## Scope

El criterio docente original acepta renta no superior a 22.000 y nota superior a 6. Es una regla del ejercicio, no asesoramiento ni una convocatoria real de becas.

## Technology / Material

C++ · fstream · excepciones

## Getting started / Reproducibility

Revisa el formato de entrada en `main.cpp` y ejecuta desde una carpeta que contenga los archivos esperados. La salida binaria corresponde al formato definido por el programa.
